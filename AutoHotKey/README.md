# AutoHotkey v2 Scripts (Windows)

Utility hotkeys for Windows (`*.ahk`):

| Shortcut | Script | Requires | Action |
|---|---|---|---|
| `Ctrl + Alt + Shift + R` | [`SuspendProcess.ahk`](SuspendProcess.ahk) | Sysinternals `pssuspend64.exe` in `%USERPROFILE%\Downloads\PSTools\` | Pause / resume active window's process |
| `Ctrl + Shift + Alt + T` | [`TranslateScreen.ahk`](TranslateScreen.ahk) | Chrome (`chrome.exe`) | Capture active monitor (`maxHeight = 720`), open Google Translate images, and paste screenshot |
