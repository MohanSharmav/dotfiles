# Karabiner-Elements Config (macOS)

Symlinked by `mise` to `~/.config/karabiner` (`karabiner.json`).

---

## Rules (`karabiner.json`)

| Rule | Status | Behavior |
|---|---|---|
| `한/영 to F18` | Configured | Maps `japanese_kana` key to `F18` (used by Hammerspoon `toggleInputLanguage`) |
| `Change Won (₩) to backtick (\`)` | Configured | In Korean IME, sends backtick (with Option modifiers) when pressing the grave/Won key |
| `Rcmd to ctrl cmd shift spacebar` | Disabled (`enabled: false`) | Optional Right Cmd -> macOS input source hotkey |
| `R cmd/alt to hangul ...` | Disabled (`enabled: false`) | Optional Right Cmd -> Gureum Hangul switch across EN/ES/FR/CSA layouts |
| `Change caps_lock to control when used as modifier, escape when used alone` | Configured | Tap `Caps Lock` -> `Esc`; hold `Caps Lock` -> `Ctrl` |
