# AutoKey Config (Linux)

Symlinked by `mise` on Linux to `~/.config/autokey/data` (`autokey/data/`).

| Folder | Contents |
|---|---|
| `Chrome/` | Tab switching (`knob next/prev tab`), focus/launch Chrome, screenshot translate |
| `Firefox/` | Tab switching (`knob next/prev tab`) |
| `Gnome/` | Desktop navigation (`Next/Prev Desktop`) |
| `My Phrases/` | Text-expansion phrase templates (`Addresses/`, sample phrases) |
| `Sample Scripts/` | Built-in reference AutoKey Python scripts |
